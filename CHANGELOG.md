## [1.0.0] - 2026-10-11

### Added

- Bilingual (Chinese / English) one-page resume sources built with Typst, sharing one style
  module (`chicv.typ`).
- Fictional sample dataset ("Zhang San" / 张三) with a placeholder ID photo and regenerable
  preview screenshots.
- Build scripts `Makefile` and `make.ps1` producing submit-level and post-level PDFs.
- `scripts/render_preview.py` helper to render README previews from compiled PDFs.
- Community files: README (English / 简体中文), LICENSE (AGPL-3.0), CONTRIBUTING, SECURITY,
  CODE_OF_CONDUCT.
- GitHub automation: CodeQL analysis workflow and Dependabot configuration.
